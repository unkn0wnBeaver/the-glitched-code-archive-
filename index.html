Archive Info

What is this archive?

The Glitched Code Archive is an unofficial repository that has mod files for the Minecraft horror mod "The Glitched Code".

Lore

The lore of the mod is found by extracting the mod JAR file...

How to install

Installation can be done in 2 ways:

1. You download the JAR from this site and in CurseForge, you create a Profile for the correct file (currently NeoForge 1.21.4) and drop the JAR into the profile’s mods folder.

2. You use the correct modloader for the correct file version (currently NeoForge 1.21.4) and drop the JAR into the installation’s mods folder.

Version updates

I get the version from the unknown creator and developer of the mod. It is not regular and a new update may come out at any time.

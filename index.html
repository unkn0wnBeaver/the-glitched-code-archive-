How to install

Installation can be done in 2 ways. 1. You download the JAR from this site and in CurseForge, you create a Profile for the correct file (currently NeoForge 1.21.4) and drop the JAR into the profiles mods folder. 2. You use the correct modloader for the correcy file version (currently NeoForge 1.21.4) and drop the JAR into the installations mods folder.
